# Vales, impresión y recuperación del cobro — 10/09/2026

## Correcciones

- El correo del vale se guardaba únicamente como metadato de una nota. Ahora se asocia el cliente por coincidencia exacta de email (se crea si no existe), se vincula al vale y se solicita explícitamente la notificación a Shopify. No se reasigna un vale que ya pertenece a otro correo.
- Tras emitir, se ofrece imprimir el código completo. Si se indicó email, se realiza un intento de envío. Los fallos conservan el vale emitido y permiten reintentar solo el correo. También se puede enviar desde el detalle de un vale existente.
- Shopify solo devuelve el código completo al emitir. La impresión desde el listado se identifica como referencia, con código enmascarado; el correo de Shopify permite entregar el código completo del vale existente.
- Tickets y vales usan texto negro, mayor tamaño y formato compacto (72 mm de contenido máximo), con escape de los textos y aviso si el navegador bloquea la ventana de impresión.
- Antes de marcar un pedido como pagado se consulta su estado. Un pedido ya pagado, incluido uno de importe cero, se registra sin repetir la mutación. La recuperación conserva el pedido y los débitos originales. Un fallo de consulta previo al pago permite reintentar sin bloquearlo como una mutación incierta.
