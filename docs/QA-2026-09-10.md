## Pruebas ejecutadas

- 21/21 pruebas Node del servidor, con Shopify simulado: recuperación de checkout, exclusión de operaciones concurrentes, no duplicación de pedidos y débitos, conciliación de respuestas perdidas, rechazo de pagos/devoluciones, devoluciones parciales, vales, contabilidad mixta, autorización y origen, y fechas de apertura.
- TypeScript: `npx tsc -b`, correcto.
- Compilación real: `npx vite build`, correcta; aviso de paquete superior a 500 kB.
- ESLint: falla con cinco errores de Fast Refresh (badge, button, tabs, CartContext, SessionContext) y un aviso de limpieza de ref en useBarcodeScanner.
- Navegador Microsoft Edge/Chromium, frontend local, todas las llamadas API interceptadas: login, formulario obligatorio de apertura, fondo 50 €, producto de nombre largo, edición a 0 €, envío del payload de checkout y pantalla de éxito.
- Anchos 1366, 1280, 1024, 768, 600, 390 y 320 px, altura 700 px: comprobación automatizada sin desbordamiento horizontal del documento en el flujo del carrito. No equivale a inspeccionar cada elemento ni cada pantalla.
- Error HTTP 500 del correo: muestra aviso de fallo y no muestra confirmación de envío. Repetido después de corregirlo.
- Cerrar y siguiente venta: vuelve al carrito vacío.

Las pruebas de navegador simulan respuestas y no validan el contrato real de Shopify. No se crearon pedidos, devoluciones, sesiones ni movimientos reales.
